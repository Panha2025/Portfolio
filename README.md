# Minh Ouddom Panha — Portfolio

A responsive, single-page portfolio for Minh Ouddom Panha, an ICT student, aspiring software engineer, and founder of Vendora. The site uses the existing HTML, Tailwind CSS CDN, JavaScript, Font Awesome, and Devicon setup.

## Features

- Responsive navigation with a mobile menu and smooth section anchors
- Light and dark themes
- Hero introduction and circular professional portrait
- Vendora founder section with a three-photo booth gallery
- Six featured projects with responsive preview cards and external links
- Competition, internship, and volunteer experience sections
- Contact details, CV download, and an email-client form fallback

## Sections

- Home
- Founder of Vendora
- Skills
- Projects
- Experience / Internship
- Competitions
- Volunteer Work
- Contact

## Featured Projects

1. Vendora — Cambodian Online Marketplace
2. Student Management System
3. MyPlanner — Smart Schedule & Task Manager
4. Bank Management System
5. AI-Sign Language Translator
6. Movie-ChatBOT

## Local Preview

Open `index.html` with VS Code Live Server. This workspace configures the server on port `5501` and uses the workspace folder as its root. The local URL is `http://127.0.0.1:5501/index.html`.

The published portfolio is available at <https://panha2025.github.io/Portfolio/>. The contact form prepares a message in the visitor's email application; the static site does not send email directly.
